# 📱 Mobile Dev App

A modern Android app that turns your phone into a developer workstation.  
It combines a Linux terminal, code editor, GitHub sync, and build toolchain — all in one place.

![Status](https://img.shields.io/badge/status-in%20development-yellow)

---

## 🚀 Features

✅ Terminal Emulator  
✅ Code Editor with Syntax Highlighting  
✅ Git + GitHub Sync  
✅ Compile & Run (Java, Python, C)  
✅ Project-Based File System  
✅ Plugin System for Extending Languages  
✅ One-Click Run  
✅ Dark Mode  
✅ Onboarding Tutorial  
✅ Command Helper & Error Explanations
